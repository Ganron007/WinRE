# Taste

## Workflow / Planning
- Before building, prefers to review the current state of a project and agree on a proper plan first. Confidence: 0.9
- Prefers implementation split into numbered phases with explicit deliverables and verification/health-check steps. Confidence: 0.7

## Tooling / Execution
- Wants tooling to support both local execution and remote (SSH) orchestration modes. Confidence: 0.6
- Prefers tools to be set up and verified on the actual target VM (e.g., FlareVM) via SSH/vmaccess, not only built/tested on the local development host. Confidence: 0.9
